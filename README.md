# English Class Studio

Editable lesson planner, classroom games, and pronunciation activities for Llano Limón Elementary School.

## Edit the website

- `index.html`: lesson planner
- `games.html`: grammar, vocabulary, and sentence games
- `pronunciation.html`: progressive pronunciation practice
- `styles.css`: colors, spacing, fonts, and layout

Open a file on GitHub, select the pencil icon, make the change, and commit it. GitHub Pages will publish the update automatically.
